There is a wide range of options for implementing Kubernetes operators in several programming languages.
After some consideration, the decision was made to use the Go programming language for implementing the operator.
This decision was made for multiple reasons.
The first one is that Kubernetes itself is written in Go, and therefore using the same language allows both the use of the native type declarations of Kubernetes, and the Kubernetes controller-runtime without needing language bindings or other abstraction layers.
Go is also by far the most popular language to implement operators in, as stated by \cite{redhatoperatorlanguages} in a post on RedHats website.

The framework decision first fell on operator-sdk by RedHat, which was chosen for its popularity and familiarity in the development team. However, it was later discovered that operator-sdk projects are not easily packaged into helm charts, and therefore are not easily installed using the helm package manager.
For this reason, the project was moved to Kubebuilder, a project by a Kubernetes \enquote{Special Interest Group}.
The development continued in Kubebuilder until the end of the project.
