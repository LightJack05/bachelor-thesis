Several resources the operator manages need to contact external data sources or contact other external services in order to obtain their data or transfer information.
The diagram below shows the relations of resources inside the cluster to external resources.

There are two external services contacted, the managed host and optionally an external git server for obtaining external files. It should be noted that these may also be multiple systems, since there may be multiple managed hosts or dependencies to other external git servers.
It is also possible that there may be additional services contacted, like Ansible galaxy or other data providers, should they be listed in the \enquote{requirements.yml} file for the playbook.
